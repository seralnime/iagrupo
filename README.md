# Connect-4 AI Tournament — IA PROYECTO

This repository contains the final project for the **Fundamentos de Inteligencia Artificial** (Artificial Intelligence) course at **Universidad de La Sabana** (9th semester). The project centers on designing, implementing, optimizing, and evaluating autonomous AI agents that compete in a **Connect-4 (4-in-a-Row)** tournament.

---

## 1. The Competition & Tournament System

### 1.1 Game Specifications
- **Board Grid**: 6 rows $\times$ 7 columns (42 cells total).
- **Goal**: Connect four tokens horizontally, vertically, or diagonally while preventing the opponent from doing so.
- **Tokens**: Red (`-1`) and Yellow (`1`), with empty slots marked as `0`.

### 1.2 Tournament Framework (`tournament/`)
- **Engine (`tournament.py`)**:
  - Implements bracket matching, round advancement, and game state transitions.
  - **Match Format**: Best-of-7 games (`best_of=7`), where the first player to win 4 matches (`(best_of // 2) + 1`) advances.
  - **Fairness & Balancing**: Alternates or samples the first-player role with an equal distribution (`first_player_distribution = 0.5`).
  - **Timeout Safeguards**: Moves are strictly time-bounded (typically 1.0s to 4.5s per turn), disqualifying agents that hang or exceed compute budgets.
  - **Dynamic Agent Discovery (`main.py`)**: Automatically scans the `groups/` directory using reflection (`find_importable_classes`) to detect and load any class inheriting from `connect4.policy.Policy`.
  - **Persistence (`versus/`)**: Match replays, board move histories, and win/loss records are serialized into structured JSON files (`match_<AgentA>_vs_<AgentB>.json`).

## 3. Agent Architectures & Models

### 3.1 AgenteOptimo (`AgenteOptimo`) — *Tournament Champion*
- **Primary Paradigms**: Monte Carlo Tree Search (MCTS) + Transposition Tables (TT) + Domain Heuristics + Alpha-Beta Minimax Endgame.
- **Key Mechanics**:
  - **UCB1 Exploration/Exploitation**: Uses Upper Confidence Bound 1 ($c = \sqrt{2} \approx 1.414$) to direct tree traversal toward promising branches.
  - **Transposition Tables (TT)**: Uses a shared hash map to cache visits and win rates for board states reached via different move sequences, drastically increasing effective search depth without redundant exploration.
  - **Immediate Win & Threat Blocking**: Scans for immediate winning moves and forced opponent blocks prior to MCTS, saving precious CPU cycles. Also eliminates "suicide moves" that leave a winning opening for the opponent directly above.
  - **Optimized Math Check (`fast_win_check`)**: Avoids costly full-board scans or cloning `ConnectState` instances by computing 4-direction contiguous token counts in-place around the placed piece (~0.05s per decision).
  - **Alpha-Beta Endgame Solver**: When remaining empty slots drop to 14 or fewer, the agent transitions from probabilistic MCTS to an exact Minimax search with Alpha-Beta pruning, center-first move ordering, and depth-based reward scaling ($\pm 1000 \pm \text{depth}$) to guarantee a forced victory or draw.

### 3.2 Group A (`ProfesorFVMC`) — *Runner-Up*
- **Primary Paradigm**: First-Visit Monte Carlo (FVMC) with persistent tabular reinforcement learning.
- **Key Mechanics**:
  - **Persistent Q-Knowledge**: Loads and saves pre-trained Q-values and visit counts (`q_table` and `n_table`) from disk (`q_knowledge.pkl` generated by `train_agent.py`), bootstrapping learning from offline games.
  - **Immediate Attack & Defense Filter**: Evaluates 1-step lookahead transitions to take immediate wins or block opponent wins before triggering rollouts.
  - **Bounded Monte Carlo Rollouts**: Runs up to 150 simulated episodes within a safe time budget (90% of `max_time`) using $\epsilon$-greedy exploration ($\epsilon = 0.1$) to continuously update Q-estimates in real time.
  - **Greedy Exploitation**: Selects actions maximizing $Q(s, a)$ for valid columns.

### 3.3 Group B (`Connect4ADPAgent` / `JaimeADP`)
- **Primary Paradigm**: Adaptive Dynamic Programming (ADP) with Reward Shaping and Value Iteration.
- **Key Mechanics**:
  - **Empirical Model Learning**: Tracks observed state-action transitions $N(s, a, s')$ and calculates maximum-likelihood transition probabilities $\hat{P}(s' \mid s, a)$.
  - **Synthetic Reward Shaping**: Injects synthetic rewards ($\pm 1000$) for known terminal win/loss states to speed up Bellman backup propagation.
  - **Time-Bounded Policy Evaluation**: Executes Bellman updates ($\Delta < \theta$) within the turn time allowance (`max_time - 0.2s`) to compute $\hat{V}(s)$ and derive $\hat{Q}(s, a)$.
  - **Center Column Prior**: Uses a positional heuristic order `[3, 2, 4, 1, 5, 0, 6]` when evaluating unknown states.

### 3.4 Group C (`OhYes`)
- **Primary Paradigm**: Uniform Random Policy.
- **Key Mechanics**: Selects an open column uniformly at random (`rng.choice(available_cols)`). Serves as an unguided baseline to confirm that all learning agents outperform random play.
